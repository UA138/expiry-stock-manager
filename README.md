# 賞味期限アラート付き在庫管理システム

食品の在庫を、店頭・倉庫それぞれの数量とロット(仕入れタイミング)ごとの賞味期限で管理するDjango製の在庫管理システムです。出庫予定を賞味期限が近いロットから順に(FEFO)差し引いて、指定日までの予測在庫を計算できます。

## 🔗 デモサイト

https://expiry-stock-manager.onrender.com

- 無料プランで稼働しているため、しばらくアクセスがないとスリープします。初回アクセス時は表示まで30秒〜1分ほどかかることがあります。
- 「新規登録」からご自身のアカウントを作成してお試しいただけます。

## 主な機能

- ログイン / 新規登録(閲覧者ロールで自動登録)
- 在庫一覧・編集(店頭在庫 / 倉庫在庫)
- 入庫登録(仕入れ商品を在庫ロットとして追加)
- 棚卸し(実在庫との差分を自動計算して一括修正)
- 出庫登録(出荷予定日・数量の登録)
- 在庫照会(指定日までの出庫予定を反映した、賞味期限別の予測在庫)
- マスタ管理(商品・カテゴリ・ユーザー)
- 入出庫履歴の閲覧・CSV出力
- 権限ロール制御(管理者 / 担当者 / 閲覧者)

## 技術スタック

- Python / Django 5.2
- PostgreSQL(本番) / SQLite(ローカル開発)
- Gunicorn + WhiteNoise(本番配信)
- Docker / docker-compose(ローカル開発)
- Render(ホスティング)

## ローカルでの動かし方

\`\`\`bash
docker compose up --build
\`\`\`

`http://localhost:8000/stock/login/` にアクセスしてください。サンプルデータを投入する場合は以下を実行します。

\`\`\`bash
docker compose exec web python manage.py seed_data
\`\`\`
