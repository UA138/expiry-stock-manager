# 賞味期限アラート付き在庫管理システム

食品の在庫を、店頭・倉庫それぞれの数量とロット(仕入れタイミング)ごとの賞味期限で管理するDjango製の在庫管理システムです。出庫予定を賞味期限が近いロットから順に(FEFO)差し引いて、指定日までの予測在庫を計算できます。

## 開発の背景

現職では、モール（楽天・Amazon・Yahoo!・auPAYマーケット）の運営とECサイト運営、実店舗運営を担当しており、
商品ごとに入荷リードタイムが異なる食品在庫を扱っています。
「お買い物マラソン」のようなモールのセールイベントや、お中元シーズンなどの繁忙期には出荷数が普段より
大きく増減するため、

- 今の在庫のままで、この先の出荷予定に対応できるのか
- 早めに発注しないと欠品してしまう商品はないか

を事前に把握しておく必要がありますが、賞味期限×ロット単位でそこまで踏み込んだ予測ができるツールが
手元になく、実務の中では都度手計算で対応していました。
この課題を解決するため、要件定義から設計・実装・テスト・デプロイまでを一人で行い、本システムを開発しました。

## 主な機能

- ログイン / 新規登録(閲覧者ロールで自動登録)
- 在庫一覧・編集(店頭在庫 / 倉庫在庫)
- 入庫登録(仕入れ商品を在庫ロットとして追加)
- 棚卸し(実在庫との差分を自動計算して一括修正)
- 出庫登録(出荷予定日・数量の登録)
- 在庫照会(指定日までの出庫予定を反映した、賞味期限別の予測在庫)
- マスタ管理(商品・カテゴリ・ユーザー)
- 入出庫履歴の閲覧・CSV出力
- 権限ロール制御(管理者 / 担当者 / 閲覧者)

## 設計で工夫した点

- **ロット単位での在庫管理**：同じ商品コードでも、仕入れタイミングが異なれば賞味期限が異なる。
  1商品コードに対して複数ロットを持てる構造にすることで、実運用に即した在庫管理を実現。
- **店頭在庫／倉庫在庫の分離管理**：カラムを分けて保持し、拠点ごとの在庫差異を可視化。
- **在庫照会(予測)による欠品リスクの可視化**：指定日までの出庫予定をFEFO順に差し引いた予測在庫を計算し、
  不足が見込まれる商品の行を赤くハイライト表示。繁忙期前の発注判断を早められるようにした。
- **モール販売可否のフラグ管理**：店頭では賞味期限ギリギリまで値引き販売できるが、モール（EC）では
  ページ上の情報だけで購入可否を判断されるため、店側で定めた期間を過ぎた商品は自動的に
  「モール販売NG」と判定し、店頭販売のみに切り替え。閲覧ミスによるクレームなど、チャネル特性の
  違いに起因するリスクを未然に防ぐ設計とした。
- **仮登録→確定の2段階ワークフロー**：入出庫は登録直後に在庫へ即時反映せず、「仮データ」として保存。
  内容確認後に「確定」操作で在庫に反映する仕組みとし、誤操作による在庫数のズレを防止。

## 品質への取り組み

- 認証・在庫一覧・入出庫・棚卸し・履歴照会・在庫照会・マスタ管理・権限制御まで、
  全62項目の手動動作確認チェックリストを作成し、全項目を確認。
- チェックリストによる確認作業の中で、入出庫登録・棚卸し画面でEnterキー操作時に数値が意図せず
  混入する不具合を発見し、修正。
